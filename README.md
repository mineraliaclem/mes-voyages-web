# Mes voyages — version web

La version web de l'appli « Mes voyages », pour iPhone (et tout navigateur).
Elle partage les mêmes voyages que l'appli Android, en direct, grâce à Firebase.

**Ouvrir l'appli :** https://mineraliaclem.github.io/mes-voyages-web/

Sur iPhone : ouvrir le lien dans **Safari** → bouton Partager → **Sur l'écran d'accueil**.

Les voyages ne sont pas stockés ici : ce dépôt ne contient que le code de l'appli.
Le code source principal (et l'appli Android) se trouve dans le dépôt privé `Mes-voyages`.
